# Benchmark READMEs

- Optimize every benchmark branch's README for human skimming, following the
  [polymarket-bootstrap README](https://github.com/imbolc/nautilus-benches/blob/polymarket-bootstrap/README.md)
- Start with the concrete Nautilus problem and a short benchmark description,
  then show runnable commands and compact, clearly labeled results tables
- Keep baseline and proposed-version sections parallel, using matching workloads
  and units; omit a proposed-version section until results exist
- Keep essential measurement caveats and required run limits beside the commands
  or results they qualify
- Link raw results and detailed methodology instead of burying results under long
  explanations; remove repetition and unnecessary implementation detail

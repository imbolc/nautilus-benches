# Nautilus issue benchmarks

Standalone, reproducible benchmarks for specific NautilusTrader issues. Each
benchmark lives on its own branch with its source, inputs, instructions and results.

| Branch | Benchmark |
| --- | --- |
| [polymarket-bootstrap](https://github.com/imbolc/nautilus-benches/tree/polymarket-bootstrap) | Polymarket instrument bootstrap and quadratic cache copying |
| [polymarket-subscription-memory](https://github.com/imbolc/nautilus-benches/tree/polymarket-subscription-memory) | Polymarket subscription-task memory |
| [polymarket-retained-refresh](https://github.com/imbolc/nautilus-benches/tree/polymarket-retained-refresh) | Polymarket stale metadata outside discovery filters |
| [feather-allocation-churn](https://github.com/imbolc/nautilus-benches/tree/feather-allocation-churn) | Feather writer allocation churn |
